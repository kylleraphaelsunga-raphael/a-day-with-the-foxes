API Request Process

From the Dataset to the Website

1. Data source: The records are stored in JSON files in the project's data folder.

2. Backend: Express reads the JSON files and provides GET endpoints.

3. Request: The frontend uses JavaScript fetch requests to call the endpoints.

4. Response: The backend returns JSON data, which the frontend processes and displays in tables.

fetch("/api/services")
fetch("/api/customers")

This implementation demonstrates GET data retrieval. It does not create, update, or delete customer records.
